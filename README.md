# 猫脳社（NEKONOSHA）

猫たちが AI 社員として働く、レトロなピクセルアートのオフィス管理アプリです。

## はじめ方

Node.js 20.9 以上（推奨：Node.js 24 LTS）を用意し、ターミナルでこのフォルダを開いて実行します。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。停止するときはターミナルで `Control + C` を押します。

iPhone で見る場合は Mac と同じ Wi-Fi に接続し、起動ログの `Network` に表示される URL を Safari で開いてください。必要に応じて Mac のファイアウォールでローカル接続を許可します。

## できること

- 広告事業部・EC 事業部の切り替え
- 社長猫「しらす」と秘書猫「ぽんず」がいるドット絵オフィス
- タスクの完了・未完了切り替えと進捗表示
- ぽんずへの指示を、選択中の事業部のサンプルタスクに追加
- サンプル通知の既読操作
- Mac・iPhone 向けのレスポンシブ表示

## ピクセルオフィス

社長室・社員デスク・ガラス会議室・ラウンジを備えた、SVG の16bit風オフィスです。鮮やかなオレンジのモジュラーソファ、ボールチェア、チューリップテーブルを配置しました。

登場する社員は、しらす（白とグレー）、ぽんず（茶トラ）、みつまめ（三毛猫）、くろごま（黒猫）、むぎ（キジトラ）、こはく（サビ猫）、おもち（白猫）の7匹です。猫または下の社員一覧をクリックすると、名前・役職・現在の仕事を確認できます。

しらす・ぽんずは担当する未完了タスク、ほかの社員は共同作業として未完了タスクに連動します。作業中はタイピング、移動中は散歩、担当する仕事がなくなるとラウンジで休憩します。タスクを未完了に戻したり、ぽんずに指示を追加したりすると作業を再開します。自動的にタスクを完了する処理はありません。

スマートフォンではマップを横にスワイプして探索できます。「全体表示」で全景に切り替えられます。アニメーションは一時停止でき、OS の「視差効果を減らす」設定にも対応しています。

すべてサンプルデータです。外部 AI API、データベース、メール送信、課金サービスは接続していません。指示への返信は定型文で、実際の AI 処理は行いません。変更内容は画面内のメモリにのみ保持され、再読み込みすると初期状態に戻ります。表示日付・通知時刻・出勤状況もデモ用です。

## 社長室（新デザイン試作）

オフィス欄の「社長室（新デザイン試作）」で、参考画像をもとにした3/4見下ろし視点の16bit風社長室を表示します。「全体マップ（現行）」で従来のマップに戻せます。

- 背景・照明・家具・猫（体、まばたき、しっぽ）・椅子の前後パーツは、すべて別々の PNG（`public/office/president/`）です。
- 配置と重なり順は `app/components/office/president-room.json` で管理しています。座標はドット絵の 320×180 ピクセル基準で、画面幅に合わせて整数倍に拡大します。
- PNG は `npm run art:office` でコード（`scripts/office-art/`）から生成しています。同じファイル名・サイズで Aseprite などの手描き PNG に差し替えることもできます。
- しらす・ぽんずは担当タスクが残っていれば作業中（タイピング）、なくなると椅子で居眠りします。

## 開発用コマンド

```bash
npm run lint
npm run typecheck
npm run build
npm start
```

`npm start` はビルド後の本番用サーバーを起動します。通常の編集には `npm run dev` を使います。

## 構成

- `app/page.tsx`：画面、サンプルデータ、操作
- `app/globals.css`：Tailwind CSS の読み込みと画面・家具のスタイル
- `app/layout.tsx`：日本語設定とページ情報
- `app/components/pixel-office.tsx`：オフィス、猫社員、タスクと連動するアニメーション
- `app/components/office/`：社長室（試作）の描画と配置データ
- `scripts/office-art/`：ドット絵 PNG の生成スクリプト

Next.js App Router・TypeScript・Tailwind CSS v4 を使用しています。猫はインライン SVG、家具は CSS で描画しているため、画像配信サービスや外部フォントへの接続も必要ありません。
